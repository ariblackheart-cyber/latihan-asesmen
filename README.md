# Latihan Asesmen

Kumpulan alat latihan mandiri berbentuk halaman web statis (HTML tunggal, tanpa build).

| Halaman | Isi |
|---|---|
| [`soft-competency/`](soft-competency/) | Materi key behavior 6 kompetensi (Gaining Commitment, Adaptability, Analysis And Judgement, Building Trust, Coaching, Collaboration), studi kasus pilih satu dan urutkan, latihan wawancara STAR, simulasi role play, dan psikotes (gambar diputar, angka, bahasa). |
| [`tebak-gambar/`](tebak-gambar/) | Game tebak gambar bahasa Inggris untuk anak: mode Look, Listen, dan Spell, 9 tema, stiker, suara pengucapan, serta foto sendiri. |
| [`kuis-tenses/`](kuis-tenses/) | Kuis tenses bahasa Inggris format papan tulis: kalimat aktif, pasif (di-), kata sifat, serta will/would/shall. Soal baru dibuat otomatis. |

## Menjalankan

Buka `index.html` di browser, atau aktifkan **GitHub Pages** (Settings → Pages → Deploy from a branch → `main` / root).

## Catatan

- Progres latihan tersimpan di browser masing-masing (localStorage).
- Di GitHub Pages, suara game anak memakai suara bawaan HP/browser, dan foto sendiri tersimpan di browser masing-masing.
- Fitur berbasis AI (penilaian STAR, simulasi role play, dan soal baru buatan AI) hanya berjalan saat halaman dibuka sebagai artifact di claude.ai. Di GitHub Pages, fitur tersebut otomatis disembunyikan atau diganti checklist mandiri; fitur lain tetap berjalan normal.
- Ini alat latihan mandiri, bukan bagian dari sistem asesmen resmi mana pun.
